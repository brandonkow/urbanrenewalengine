## Acceptance gate for the next actual model
1. Match the official parcel/strata record to the watchlist site and assembled extent. Record a dated source reference and permitted use; exclude owner personal data from GitHub and exports.
2. Establish the appropriate denominator (legal interests, not occupants), mixed-use share, lot/unit area basis and supported existing-interest value assumptions.
3. Keep negotiated uplift, holdout allowance, relocation and funding terms explicitly separate assumptions. Do not treat a model result as owner agreement.
4. Add evidence using the repository add-evidence workflow, implement the new site's owner inputs and record numerical effects. Preserve existing golden values unless a documented correction is intended.
5. Run full numerical, cash-flow, memo, saved-version, UI and screenshot checks. Review the new model's outputs and source limitations.
6. Mark Build 6.5 complete only after actual evidence-supported models are delivered, or after the user explicitly changes the scope. An empty input template or generic placeholder does not complete it.
