# Committee decision memo (Build 6.2)

Open Committee memo and choose any site, the recorded base, DBKL incentive as read or current live inputs. Generate a snapshot, then print/save as PDF or export standalone HTML or JSON. Rationale is required for a proposed hold, further-investigation or decline position. These are analyst proposals, not recorded committee approval.

The report captures economics, explicit assumptions, cash-flow settings/results, evidence gaps, due-diligence status and linked evidence with its existing provenance and dates. Current live triggers are labelled separately because they can use different inputs from the selected memo scenario. An unmodelled site produces missing-model notices, never a fabricated result. Saved absolute cash-flow consideration and facility amounts remain explicit when a different scenario is selected.

Generation detaches the report from workspace objects. Changes to controls or underlying data do not alter the displayed snapshot until Generate is pressed. HTML and JSON exports use that snapshot. Notes are session-only; no owner personal fields are added. Do not enter private details into free text. Standalone HTML is script-free and escaped; source links only accept credential-free HTTP(S). The JSON snapshot includes full captured assumptions and transaction rows for reproducibility.

Printing hides application controls and expands the quarterly profile appendix. The report may span several pages, including the evidence register; it is not constrained to an executive-summary page count. No finance formula, golden value, trigger, source record or consent state changes when creating a memo.

Validation covers every site and basis, missing models, source and scenario isolation, safe HTML, selected-snapshot export, mobile/dark layout and print controls. GitHub CI renders a synthetic committee memo PDF for paginated visual inspection. See the continuation programme for acceptance.

The source appendix includes site-specific records, relevant shared planning/cost references and any documents linked to the site’s latest reviews, including retained snapshots. It does not include unrelated land-deal records from the global register.
